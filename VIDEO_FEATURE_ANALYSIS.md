# SparkCart Mall — Video Feature Analysis

The reference video was reviewed and the useful e-commerce/admin patterns were adapted without copying branding or source code.

Included in this build:
- KPI dashboard: total sales, today's sales, products, low stock
- 7-day sales visualization
- Top-selling product summary
- District/division order map
- Inventory and low-stock quick update
- Orders search/filter and status workflow
- Order detail modal with address, products, totals and payment details
- Customer WhatsApp action from order details
- Product management with multiple images, video, stock, price, old price, SKU, color/size
- Product-specific deep links for Facebook posts
- Customer order tracking using Order ID + phone
- bKash/Nagad/Rocket checkout fields: sender number, optional transaction ID, amount, payment time
- Admin payment-number settings
- Existing Lucky Spin / coupon functionality retained

Not intentionally copied:
- Other site's brand/logo/name
- Exact visual assets or proprietary content
- Any unnecessary feature that does not fit SparkCart Mall

Important: this feature build does not seed or replace products. It is designed to be applied to the existing database.
