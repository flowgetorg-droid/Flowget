The previous catalog reused generic remote Unsplash images for many different products, causing mismatches. This version uses local per-product SVG product visuals so images load reliably from GitHub/Netlify. Prices were revised upward to more realistic Bangladesh retail targets; final selling prices should still be adjusted to your actual supplier cost, delivery, ad spend and desired margin. Run CATALOG_PRICE_IMAGE_FIX.sql after the original catalog SQL. It uses UPDATE only and does not delete products, orders or customers.
