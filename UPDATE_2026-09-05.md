# SparkCart Mall — Update 2026-09-05

This update is additive and keeps the existing GitHub / Netlify / Supabase structure.

## Changes
1. Added the supplied SparkCart Mall logo to the website header.
   - `assets/brand/sparkcart-logo.png`
2. Fixed the Kitchen Storage & Accessories category icon to a kitchen emoji.
3. Added separate ordering flows:
   - **Cart Order:** checkout orders all products currently in the cart.
   - **Quick Order:** orders one selected product directly without adding it to the cart.
   - Quick Order is available from product cards and Product Details, which also makes shared product links easier to order.
4. Updated bKash / Nagad / Rocket payment instructions to explicitly say **Send Money** and show the configured payment number.
5. Fixed the Admin panel's missing dashboard/visitor wiring:
   - Visitor Activity tab is now selectable.
   - Visitor stats and per-visitor activity are loaded from Supabase.
   - Dashboard sales/inventory/map functions are wired.
   - Banner management functions are wired.
6. Existing product, order, admin and Supabase configuration files were retained.

## Important Supabase step
Visitor tracking requires the database migration to have been executed in the Supabase SQL Editor at least once:
- `VISITOR_ACTIVITY_MIGRATION.sql`

The SQL is additive/idempotent and is intended to preserve existing product/order data.
